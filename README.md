**这是什么**

保存水源社区的帖子的油猴脚本，以及配套的离线查看器

---

**使用库**

1. fflate@0.8.2
2. FileSaver@2.0.5
3. asyncPool（直接复制使用）

---

**目前已经实现的功能**

1. 获取cookies，网址，topicID，raw
2. 最简陋的按钮交互
3. zip文件写入与下载
4. 较小图片、附件、视频、音频下载（已经发现short-url）
5. 并行下载以及错误重试
6. 获取帖子间的回复关系
7. 部分水源方言语法

---

**目前没有实现的功能**

1. 较大图片、附件、视频、音频下载（目前不指导为什么报错）
2. 表情、头像
3. 另一部分水源方言语法
